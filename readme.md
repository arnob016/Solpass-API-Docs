# SolPass

**SolPass** is a Solana-based royalty and settlement protocol built for ticketing platforms.  
It provides a trustless way to manage event funds, enforce resale royalties, and ensure transparent distribution to teams, artists, and organizers.

When a partner initializes an event, SolPass creates an on-chain contract that stores essential details such as royalty percentage, event metadata, and payout wallets. Throughout the event lifecycle, partners send sale and resale information to SolPass, and the protocol securely routes funds into an escrow account.

At the end of the event, SolPass automatically distributes all accumulated funds from escrow to the correct recipients, ensuring accurate, verifiable, and tamper-proof settlements without manual reconciliation.
